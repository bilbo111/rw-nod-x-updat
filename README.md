# rw-nod-x-updat

Автоматическое обновление **Xray-core** внутри контейнера `remnanode`. 

Скрипт сам определяет архитектуру сервера, скачивает последнюю версию Xray с GitHub, обновляет бинарник внутри контейнера и предлагает добавить задачу в cron.

---

## 🚀 Быстрая установка (одна команда)

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/bilbo111/rw-nod-x-updat/main/update_xray.sh)
```

**Что произойдёт:**
* Скрипт скачается и установится в `/opt/remnanode/update_xray.sh`
* Определит архитектуру сервера (amd64 / arm64 / arm32)
* Проверит текущую версию Xray в контейнере
* При необходимости скачает и установит последнюю версию
* Предложит добавить автоматическую проверку в cron

---

## ✨ Что умеет скрипт

* **Автоопределение** архитектуры сервера
* **Получение** последней версии через GitHub API
* **Сравнение** с текущей версией внутри контейнера
* **Скачивание** нужного архива
* **Копирование** бинарника в работающий контейнер
* **Выставление прав** и перезапуск контейнера
* **Интеграция с Cron** (предложение добавить проверку ежедневно или раз в неделю)
* **Логирование** при работе в фоновом режиме через cron

---

## 🛠 Использование

### Ручной запуск после установки
```bash
/opt/remnanode/update_xray.sh
```

### Настройка Cron (Автоматическое обновление)
При согласии во время первой установки скрипт добавляет одну из задач:

* **Каждый день в 04:00**
  ```cron
  0 4 * * * /opt/remnanode/update_xray.sh >> /var/log/xray_cron_update.log 2>&1
  ```
* **Каждое воскресенье в 04:00**
  ```cron
  0 4 * * 0 /opt/remnanode/update_xray.sh >> /var/log/xray_cron_update.log 2>&1
  ```

Логи работы планировщика сохраняются в: `/var/log/xray_cron_update.log`

## 📋 Требования

* Docker
* Запущенный контейнер с именем `remnanode`
* Права `root` (sudo)
* Утилиты `curl` и `wget` (обычно уже предустановлены в системе)
